Machine definitions determine the file extension, coordinate rules, program text, motion syntax, and machine capabilities used by machine output. Duplicate a built-in definition or import JSON in **Manage machines** before editing a custom one.

## Built-in machines

| Definition | Extension |
| --- | --- |
| **Generic** | `.nc` |
| **GRBL 1.1** | `.nc` |
| **grblHAL** | `.nc` |
| **LinuxCNC** | `.ngc` |
| **Mach3** | `.tap` |
| **UCCNC** | `.txt` |

## Definition groups

| Group | Controls |
| --- | --- |
| Program | File extension, comments, header, and program end. |
| Coordinates | Units, origin mapping, axis directions, and numeric format. |
| Motion commands | Rapid, linear, and arc commands and the supported arc format. |
| Feed and spindle | Feed and spindle command letters and related output. |
| Tool change | Whether the definition can emit tool changes and their command sequence. |
| Canned cycles | Supported drilling cycles, or no canned cycles. |
| Coolant | Coolant command support. |

## Validation

PureCutCNC validates a machine definition before using it. Export can be blocked when a selected operation needs an output capability the active definition does not provide, such as a tool change. Test any custom definition with a safe, simple program and your controller documentation before using it on a job.

## Rotary definition

<Availability kind="preview" />

The optional `rotary` block describes the rotary drive. Without it the definition has no
rotary axis. Configure it in the machine editor or its raw JSON:

| Field | Meaning |
| --- | --- |
| `rotary.about` | Required `"x"` or `"y"`: the project axis the bar lies along. |
| `rotary.drive` | Required `"own"` for output word A, or `"borrowed"` for the other horizontal motor's word. Linear travel on that motor is then unavailable. |
| `rotary.reversed` | Reverses the rotary sign; defaults to `false`. |
| `rotary.inverseTimeFeed` | Commands `on` and `off`, defaulting to `"G93"` and `"G94"`. `null` means no inverse-time capability and refuses turning feed cuts. Set nonstandard commands in raw JSON. |
| `motion.machineCoordinateCommand` | Prefix for a machine-coordinate rapid. If absent, G-code uses `G53` plus the rapid command; `null` declares no such move. Required for safe indexing when tool-length compensation cannot establish clearance. |
| `motion.machineSafeZ` | Machine-coordinate retract height in millimetres, default 0. It is independent of project origin and units; 0 assumes the machine's homed Z zero is at the top of travel. |

Top and Bottom bar programs retract to machine safe Z before turning to their opening angle.
An unsafe turn is refused when no active tool-length compensation or machine-coordinate retract
can establish clearance. Check these values against the actual controller and homing setup.
See [Machines](/guide/cam-setup/machines/#rotary-axis) and
[Rotary export](/guide/rotary/rotary-operations/#rotary-export).

## Plasma definition

<Availability kind="experimental" />

`machineKind` is `"router"` or `"plasma"`; absence retains router behaviour. A `plasma` block
requires plasma kind and the G-code output dialect. The built-ins are
**QtPlasmaC (experimental)** (`.ngc`) and **Grbl plasma (OpenBuilds CONTROL) (experimental)**
(`.gcode`). Their blocks describe these fields:

| Field | Meaning |
| --- | --- |
| `plasma.torchOnCommand`, `plasma.torchOffCommand` | Required torch commands. |
| `plasma.thcOnCommand`, `plasma.thcOffCommand` | Optional torch height control commands. Blank optional commands are absent. |
| `plasma.pierceMode` | `"controller"` or `"gcode"`; determines which other fields are required. |
| `plasma.materialSelectCommand` | Controller mode: required material selection, using `{materialNumber}` from the torch. |
| `plasma.materialWaitCommand` | Controller mode: required wait after selecting material. |
| `plasma.materialFeedCommand` | Controller mode: required material-feed command, emitted after the wait. |
| `plasma.touchOff.probeCommand` | G-code mode: required probe command, `G38.2` in the built-in. |
| `plasma.touchOff.probeDepth` | Positive distance below Z zero in mm; built-in 30. |
| `plasma.touchOff.probeFeed` | Positive probe feed in mm/min; built-in 100. |
| `plasma.touchOff.setZeroCommand` | Required Z-zero command; built-in `G10 L20 P0`. |
| `plasma.touchOff.switchOffset` | Nonnegative mm offset; absent means zero. Emitted as negative Z when setting zero. |

Controller mode requires the material sequence and forbids `touchOff`. G-code mode requires
`touchOff` and forbids the material sequence. Torch dimensions and feeds belong to the tool;
QtPlasmaC's actual cutting settings belong to the controller's material table. See
[Plasma machines](/guide/cam-setup/machines/#plasma-machines) and
[Plasma programs](/guide/verify-export/gcode-export/#plasma-programs).

## ShopBot output dialect

<Availability kind="preview" />

**ShopBot (SBP)** uses `.sbp` and `outputDialect: "opensbp"`. An absent `outputDialect` uses
G-code. The dialect has no editor control; a duplicate of ShopBot keeps it. PureCutCNC writes
the entire part file, so G-code commands and templates do not control its output. The editor
shows **Name**, **File extension**, and an explanatory note; axis mapping, number format, and
arc support are in **Advanced (raw JSON)**. See
[ShopBot part files](/guide/verify-export/gcode-export/#shopbot-part-files) for output commands.
