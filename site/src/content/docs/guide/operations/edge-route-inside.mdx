**Edge route inside** follows the inside edge of a closed subtract profile, offset by the tool
radius. It can also follow the subtract counters inside an Add outline text feature without
expanding the text. Use it for a precise internal contour or opening when a Pocket would remove
unnecessary material.

## Requirements

| Requirement | Value |
| --- | --- |
| Target features | Closed subtract features, or Add outline text with enclosed subtract counters; regions are supported by contour routing only |
| Tool | Flat or ball endmill |
| Passes | Rough or Finish |

## Parameters

Shared settings are documented in [Common operation parameters](/guide/operations/common-parameters/).

| Parameter | Description |
| --- | --- |
| **Strategy** | Uses a contour, or a Trochoidal rough pass that leaves stock for contour finishing. |
| **Stock to leave radial** | Reserves wall material for the finish contour. |
| **Vertical overcut** | Takes the final pass into the spoilboard, up to the project limit. See [Vertical overcut](#vertical-overcut). |
| **Tabs** | Associates a tab set where the contour needs to retain material. |
| **Rest machining** | Creates a follow-up operation for material the current tool cannot reach. |
| **XY approach & exit** | Is available only when its entry and target conditions are compatible. |

## Strategies

Rough passes can use **Contour** or **Trochoidal** routing. Finish passes always use a contour.
XY approach and exit needs a ramped entry on a contour route; it is unavailable for a
trochoidal rough edge route or when a region filters the target.
See [Trochoidal cutting](/guide/strategies/trochoidal-cutting/#edge-routes) and
[Entry and exit moves](/guide/strategies/entry-and-exit/).

## Vertical overcut

<Availability kind="preview" />

**Vertical overcut** takes the final pass below the stock bottom, into the spoilboard, so a
through cut leaves no skin. First set **Max spoilboard cut depth** on the **Project** node. It
defaults to 0, and an operation's overcut can be from 0 up to that limit. A larger value is
refused: the operation shows an error, no toolpath is generated, and export is blocked until
you correct it.

The overcut is measured from the stock bottom. For a target that cuts through, the final pass
goes exactly that far below the stock bottom; **Stock to leave axial** still applies to the
passes above it. A target that does not reach the stock bottom gets no overcut. When none of
the operation's targets cuts through, its properties say the overcut is set but not applied.

An applied overcut is a warning with the amount: in the operation properties, in the export
dialog's **Warnings**, as a comment in the program, and in the setup booklet.

## Limitations

An Add text feature without counters, such as L, has no inside subtract contour to route and is
refused. See [Machining text](/guide/design/text/#machining-text) for the text-specific target rule.

<Aside type="caution" title="Check entry and tabs together">
	Trochoidal roughing uses Helix or Plunge entry. Tabs require a compatible Helix entry, so review
	the warnings and the simulated final contour before running the program.
</Aside>

## Verifying the result

Inspect the offset side, entry, tab bridges, and any remaining wall stock in the toolpath preview.
