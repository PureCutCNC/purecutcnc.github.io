**V-carve offset** follows progressively narrower inset contours and lowers the V-bit at each
pass. Use it for signage, engraving, and decorative closed geometry that benefits from a tapered
groove.

<Screenshot src={offsetResult} alt="Large lettering carved by a V-carve offset pass, with broad tapered walls and a flat floor where the letters are widest" caption="The offset pass clears the inside of each letter, leaving tapered walls." />

## Requirements

| Requirement | Value |
| --- | --- |
| Target features | Compatible closed machining features or closed lines; optional closed regions filter the cut |
| Tool | V-bit with its included angle set |
| Passes | Single pass |

## Parameters

Shared settings are documented in [Common operation parameters](/guide/operations/common-parameters/).

| Parameter | Description |
| --- | --- |
| **Max carve depth** | Limits the depth of the tapered groove. |
| **Stepdown** | Limits how far the tool descends between generated contours. |
| **Cut direction** | Chooses conventional or climb direction. |

## Limitations

<Aside type="caution" title="Use the actual V-bit angle">
	The selected tool’s V angle determines the groove geometry. Verify the tool definition and
	preview the depth before cutting finished artwork or a workpiece with limited thickness.
</Aside>

## Verifying the result

Check that all intended letters and interior details have toolpaths and that the resulting groove
does not exceed the material or desired depth.
