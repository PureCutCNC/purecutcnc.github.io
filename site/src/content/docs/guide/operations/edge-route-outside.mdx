**Edge route outside** follows the outside edge of a closed add or model profile, offset by the
tool radius. It can also route around the add islands enclosed by a Subtract outline text feature.
It is the normal operation for separating a finished part from surrounding stock.

## Requirements

| Requirement | Value |
| --- | --- |
| Target features | Closed add or model features, or Subtract outline text with enclosed add islands; regions are supported by contour routing only |
| Tool | Flat or ball endmill |
| Passes | Rough or Finish |

## Parameters

Shared settings are documented in [Common operation parameters](/guide/operations/common-parameters/).

| Parameter | Description |
| --- | --- |
| **Strategy** | Uses a contour, or a Trochoidal rough pass that leaves stock for contour finishing. |
| **Tabs** | Associates the tab set that retains the part during the final cut. |
| **Stock to leave radial** | Reserves material for the finish contour. |
| **Rest machining** | Creates a follow-up operation for material the selected tool cannot reach. |

## Strategies

Rough passes can use **Contour** or **Trochoidal** routing; finish passes always use a contour.
For multiple selected targets, the operation attempts one combined outer contour. Targets with
different effective depth spans cannot use that combined route; separate them by depth or align
their top and bottom levels rather than trusting separate contours through an internal overlap.
See [Trochoidal cutting](/guide/strategies/trochoidal-cutting/#edge-routes).

## Limitations

For Subtract text, the route follows only the enclosed add islands, not the outer letter outlines.
See [Machining text](/guide/design/text/#machining-text) before selecting the target.

The route keeps the cutter clear of neighbouring parts' retained material. A part inside
another part's hole or a letter counter can be routed when there is enough cutter clearance;
the opening is not treated as solid material. A nearby sharp corner does not by itself stop
the route if the cutter fits past it.

If neighbouring material blocks part of the contour, the toolpath reports **Outside route
around … was kept clear of neighbouring parts — part of its outline is left uncut.**
The part may remain attached there. Adjust the layout or tool, regenerate, and inspect the
remaining outline; a partial route is not a complete separating cut.

<Aside type="danger" title="Safety: outside routing can release the part">
	Use tabs and secure workholding before an outside route reaches the final depth. If combined
	contours or mixed feature depths cause a warning, resolve it in the design or operation before
	exporting; do not assume the part will remain supported.
</Aside>

## Verifying the result

Confirm the tool stays on the outside of the intended contour, preserves each tab, and does not
conflict with clamps or the planned machining order. For a [nested layout](/guide/design/arranging/#nest-on-stock),
inspect each part's route and entry, including parts placed inside holes. Check warnings for
uncut outline sections before assuming a part will separate.
