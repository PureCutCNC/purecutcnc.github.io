**Engrave** follows an open or closed sketch path at a fixed carve depth. Choose Direct for text,
marks, and decorative lines; choose Trochoidal to cut a wider functional slot.

## Requirements

| Requirement | Value |
| --- | --- |
| Target features | Open or closed machinable paths; optional closed regions filter the cut |
| Tool | Compatible cutting tool |
| Passes | Single pass |

## Parameters

Shared settings are documented in [Common operation parameters](/guide/operations/common-parameters/).

| Parameter | Description |
| --- | --- |
| **Carve depth** | Sets the fixed depth of the path. Stepdown applies when this exceeds a safe per-pass depth. |
| **Strategy** | Chooses Direct centerline cutting or Trochoidal slot cutting. |
| **Trochoidal cut width** and **Trochoidal advance** | Control the channel and orbit spacing for a trochoidal slot. |

## Verifying the result


<Aside type="caution" title="Check the actual top Z">
	Inspect the preview where a path crosses or sits inside other features. Confirm the depth and
	clearance are appropriate for the enclosing surface before machining.
</Aside>
