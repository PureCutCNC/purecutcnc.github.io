PureCutCNC is a 2.5D and 3D CAD/CAM program for CNC routers. You draw or import a part, assign
machining operations to it, check the toolpaths in 3D and in simulation, and export G-code for
your machine. It runs in a desktop or tablet browser and as a desktop app for macOS, Windows, and
Linux. It needs no account, and your projects stay on your own computer.

This guide describes the current app. Pages and sections marked **Preview Build** cover features
that are not in a stable release yet.

## Workflow


<Screenshot src={workflowOverview} alt="PureCutCNC workflow from project setup and design through CAM, verification, export, and machine-side checks" />
A typical job goes through these steps. You can return to any of them at any time: toolpaths are
generated again whenever the design or the machining settings change.

1. **Set up the project.** Create or open a project, then check its stock, origin, and units.
2. **Design the part.** Draw features or import SVG, DXF, STL, OBJ, or STEP files, and give each
   feature its role and its Z top and Z bottom.
3. **Plan the machining.** Add tools, then add operations to the features they should cut, or let
   CAM Plan propose a set of operations for you to review.
4. **Set up the cut.** Choose each operation's settings and strategies, and add tabs and clamps.
5. **Verify.** Check the toolpaths in the 3D view and the simulation, and resolve any warnings.
6. **Export.** Choose the machine, check which operations are exported, save the G-code, and check
   it on the machine before cutting.
