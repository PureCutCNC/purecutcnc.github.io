PureCut CNC is a 2.5D + 3D CAD/CAM workspace. You draw or import geometry, assign machining
operations to it, check the result in 3D and simulation, and export G-code when it looks right.
It runs as a desktop app on Windows, macOS, and Linux, and in any modern desktop or tablet
browser. No account is needed, and your project data never leaves your machine.

New to PureCut CNC? Start with the [Quick Start](/quickstart/): it takes you from a blank
project to exported G-code in a few minutes.
