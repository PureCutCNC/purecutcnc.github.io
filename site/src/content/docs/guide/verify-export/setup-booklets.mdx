A setup booklet is a PDF summary for one selected operation. It keeps the operation, tool, settings, and its captured preview together for use at the machine.

## Before you start

- Select the operation in the CAM panel and make sure it has a valid toolpath.
- Treat the booklet as setup documentation, not as controller output. You still need to verify the exported G-code and physical setup.

## Export a setup booklet

<Steps>

1. Select one operation in the CAM panel.

2. Use **Export booklet (PDF)** in the selected operation's action row in the CAM panel.

3. Wait for the operation toolpath and snapshot to be captured, then choose where to save the PDF.

</Steps>

While exporting, the booklet button shows a spinner and is disabled. Its tooltip and the status
line above the operation's properties show the current stage:

- **Booklet: preparing the toolpath...**
- **Booklet: drawing the overview picture...**
- **Booklet: building the PDF...**
- **Booklet: choose where to save the PDF...**

Wait for the save step to finish or cancel before starting another export.

## Contents

The PDF is built from one captured revision. It includes the selected operation’s setup information, tool, parameter rows, toolpath summary, and preview image. Dense toolpaths in the overview picture are simplified in the same way as the canvas preview.
The booklet's move counts, times, and bounds still come from the full toolpath. The output uses
the current interface language where localized text is available.

## Setup and program identity

<Availability kind="preview" />

For a two-sided job, the booklet names the operation's setup and program number. It also
records the setup orientation, registration references, operator notes, and cross-face targets.
Check these against the numbered program you intend to run. Registration entries record your
locating plan; they do not prove that the stock is registered correctly. See [Setups and faces](/guide/fundamentals/setups-and-faces/).
