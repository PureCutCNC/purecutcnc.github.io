Use CAM Plan to make a starting set of operations from the features already in your project. It proposes compatible operations and tools, but does not create or change operations until you review the plan and choose **Create operations**.

## Before you start

- Set up the stock and create the features you intend to machine. CAM Plan bases its recommendations on their role, closed shape, depth, and whether they reach the stock bottom.
- See [How features become toolpaths](/guide/fundamentals/features-and-roles/#how-features-become-toolpaths) for why those feature properties affect the available recommendations.
- Add suitable tools to the project or keep the bundled tool library available. A proposed operation needs a compatible tool with enough cutting depth before it can be created.
- Read [Working safely](/guide/start-here/safety/) before preparing a job for a real machine.

## Create a CAM Plan


<Screenshot src={planRecommendations} alt="The CAM Plan dialog with two recommended pocket operations listed and checked on the left, and on the right the reason the operation was chosen, the tool it picked and why, and its main parameters" caption="The plan explains each operation it proposes, and every part of it can be edited or switched off before you create it." />
<Steps>

1. Open the **CAM** panel and select **Plan**. The **CAM Plan** dialog opens with a summary of proposed operations, tools, existing operations, and features that need review.

2. Read each item in **Recommended plan**. CAM Plan can suggest rough and finish passes for pockets and edge routes, drilling for matching circular subtracts, surface operations for supported imported models, and shared tabs for matching separating edge cuts. Existing operations stay unchanged.

3. Select a proposed operation to inspect its reason, tool choice, target, and main parameters. Change values where the proposal does not match your material, cutter, machine, or intended result.

4. Clear an operation's inclusion checkbox to leave it out. If the plan lists a feature under **Needs explicit review**, either enable an operation that covers it or confirm that no created operation will cover that feature.

5. Use **Refresh recommendations** after changing the project or when an operation’s rest pass is marked stale. Move an operation only when its dependencies still allow the order; the dialog prevents moves that would place an operation before one it depends on.

6. Check shared tab dimensions and whether tabs are enabled for every separating edge cut. Then select **Create operations** to add the included, valid operations together.

</Steps>

<Aside type="danger" title="Safety: verify every proposed cut before machining">
CAM Plan recommendations can be incomplete or unsuitable for your stock, cutter, workholding, or machine. Before running the machine, verify each enabled operation’s target, tool, depth, feeds, entry, tabs, and order; then inspect the toolpaths and perform the normal dry-run and workholding checks in [Working safely](/guide/start-here/safety/).
</Aside>
