An operation connects selected features, a tool, and cutting settings to a toolpath. Use the operations panel to add operations, then review their targets and settings before you generate or export anything.

## Before you start

- Create the features and stock that you want to machine, and add the required tools to the project.
- Read [Features, roles, and depth](/guide/fundamentals/features-and-roles/) to understand why an operation accepts only particular feature roles and shapes.
- Read [Working safely](/guide/start-here/safety/) before preparing a job for a machine.

## Adding


<Screenshot src={addMenu} maxWidth={400} alt="The Add operation menu with Pocket opened to show its illustration, description and key points, and V-carve offset, V-carve medial and Edge in listed below with their Rough, Finish and Both buttons" caption="Opening an entry shows what the operation does and what it needs before you add it." />
<Steps>

1. Open the operations panel, then use the Add button for the face in view.

2. Review the compatible choices in the 2D or 3D group. The menu can offer **Rough**, **Finish**, or **Both** when an operation supports separate passes; it also identifies choices unavailable for the current selection.

   Each information card explains the target requirement. Use **Select all compatible** when the
   current selection contains several valid features; review the separate unavailable section
   rather than treating it as an operation recommendation.

3. Select an operation and pass. It is added to the operations list with the current compatible selection as its target.

4. Select the new row to edit its properties. Use [Choosing an operation](/guide/operations/) when you need help matching the operation to the feature and intended cut.

</Steps>

When the Add button or a feature’s **Create operation** menu picks a tool for a new pocket, edge route, follow-line cut, or 3D roughing or finishing operation, it aims for a cutter no wider than **1/4 in (6.35 mm)** and may choose a smaller one for a narrow target. It checks project tools before the bundled library. If none fits that size limit, it can choose the smallest compatible tool available, which may be wider than the limit. Inspect the selected tool, reach, and target before generating a toolpath. [CAM Plan](/guide/cam-setup/cam-plan/#create-a-cam-plan) shows the reasoning for its proposed tool choices.

## Operation identity

<Availability kind="preview" />

**Kind** is plain text identifying the operation. An empty **Description** shows **+ Add note**;
click it to write a note.

## Context menu

Use a feature’s context menu to create a compatible operation, or to add that feature to and remove it from an existing operation. The menu offers **Create operation**, **Add to operation**, and **Remove from operation** only when the selected feature is compatible.

## Targets

<Availability kind="preview" />

**Cuts** in **What it cuts** lists the operation's targets. Hover a row to highlight its feature
on the canvas. Click its × to remove it; the last machining target cannot be removed. Folder
members are grouped under collapsible folder headings. Region rows are marked **filter**,
and a stock target is shown as **Stock**.

Use a feature's **Add to operation** or **Remove from operation** context action to change the
list. A region limits where an operation may cut rather than becoming a cut itself.

If a target is unavailable, check its role, closed profile, and the operation's requirements.
Construction geometry cannot be a machining target. Outline text can supply counters and islands
without expansion; see [Machining text](/guide/design/text/#machining-text).

## List


<Screenshot src={operationList} maxWidth={400} alt="The Operations tab with Add, Plan, Export, and Setup properties buttons, a show-all eye and the generation gear, listing six operations, each with an enable dot and buttons to show its toolpath, duplicate it and delete it, with the selected operation’s Name, + Add note, Kind, and Pass below" caption="Selecting an operation opens its parameters in the properties below the list." />
Within each setup, the **Operations** list is the machining order. Drag a row to reorder it, use its controls to enable or disable it, and show or hide its toolpath. The show/hide-all eye changes every operation at once. Duplicate an operation when you need a related variation, or delete one that is no longer part of the plan. The expanded view also provides per-operation G-code and setup-booklet exports.

<Aside type="caution" title="Order changes affect the job">
An operation list is not just an organization tool: it controls the order in which the planned cuts run. After reordering, confirm that internal cuts, finishing passes, and separating outside cuts still occur in an order suitable for the material and workholding.
</Aside>

## Generation

<Availability kind="preview" />

<Screenshot src={generationMenu} maxWidth={341} alt="The toolpath generation menu reading Toolpaths up to date above a Stop button, and a Display section setting the 2D renderer to GPU or Canvas" caption="The generation menu reports calculation status. In the Preview Build, its Display section also controls the Sketch toolpath renderer." />

Toolpaths generate when an enabled operation is visible. The generation gear menu shows
**Toolpaths up to date**, **Generating (…)**, **Generation paused**, or **Generation failed**.
Use **Stop** to pause generation, **Resume** to continue, or **Retry** after a failure.

Generation runs on a background thread. If it cannot start, the menu reports **Background thread
unavailable; using the main thread.** Generation continues, but **Stop** cannot interrupt an
operation already running on the main thread. There is no thread-choice control.

Under **Display**, **2D renderer** offers **GPU** and **Canvas** for the Sketch toolpath overlay.
GPU is the default; a saved renderer choice is kept. If GPU rendering cannot start, the gear is
flagged and the menu shows **GPU unavailable; using Canvas.** Use **Retry GPU** to try again.
The **Feature colors** legend starts collapsed and keeps a saved choice.

<Aside type="danger" title="Safety: inspect every generated toolpath">
A visible toolpath is not proof that the machine can run it safely. Before machining, check the target, tool, depths, entry and retract moves, clearances, tabs, and workholding; then inspect the result in [Toolpath preview](/guide/verify-export/toolpath-preview/) and follow the dry-run guidance in [Working safely](/guide/start-here/safety/).
</Aside>

## Operations by setup

<Availability kind="preview" />

In a two-sided job, the operations toolbar keeps **Add to Top** or **Add to Bottom**, **Plan**, **Export**, the
show/hide-all eye, and the generation gear on one row. Add follows the face in view.
Setup cards group the operations: **Bottom 1 P02** means one Bottom operation
in program 02, and an empty card reads **No operations**. Each card has its own setup gear.
A setup header shows a generating spinner while any of its operations is generating, even
when the card is collapsed. Paused generation shows a pause icon instead. The badge disappears
when generation finishes.

Use **Move…** beside **Setup** in an operation's properties to move it to an existing setup.
Review the targets the move removes before confirming **Move operation**. See [Setups and faces](/guide/fundamentals/setups-and-faces/) for
setup properties, registration, and cross-face targets.

## Plasma operation choices

<Availability kind="experimental" />

In a **Plasma** project, the Add menu offers **Plasma through-cut** and omits milling rows.
In other project types, it lists that operation as unavailable with **Needs a plasma project.
The type is chosen when the project is created.** The machine choice does not enable it.
Retained operations of the other family stay editable with **not for this project type** and
a count of cuts left out of export. See [Plasma through-cut](/guide/operations/plasma-through-cut/).

## ShopBot operation export

<Availability kind="preview" />

With **ShopBot (SBP)** selected, the per-operation export button's tooltip is
**Export ShopBot part file for this operation**. It opens the ShopBot export dialog for that
operation. Review its checklist and preview before **Export .sbp**.
