## Tools overview

The **Tools** tab in the CAM panel manages the project's tool library. Tools are stored
per-project in the `.camj` file. Each operation references a tool from this library.

You need at least one tool defined before you can assign it to an operation. The quickest way to
get started is to import a tool from the bundled library.

## Automatic tool choice

<Availability kind="preview" />

Automatic tool selection for a new operation and CAM Plan considers only tools in the
project's unit system, including tools imported from the bundled library. It never converts
a tool in the other units to make an automatic choice. Existing operations keep their assigned tools;
you can still assign a tool in either unit system by hand.

## Managing

Use the tools list to add, duplicate, and remove the project’s cutters. Select a tool to edit its properties in the panel beside the list.

### Adding tools

### Import from library

Click **Import from library…** in the Tools tab. The **Import tools from library** dialog
opens over the app, so you browse the library in a full-width space instead of the narrow
side panel.

The milling library offers 34 tools:

- **Imperial**: flat endmills from 1/16″ to 3/4″, ball endmills from 1/16″ to 1/2″, V-bits of
  30°, 60°, 90°, and 120°, and an 82° countersink.
- **Metric**: flat endmills from 1 mm to 12 mm, ball endmills from 1 mm to 8 mm, and V-bits of
  30°, 60°, 90°, and 120°.

Finding what you want:

- **Search** by name or diameter. The field is focused as soon as the dialog opens.
- **Type filter**: **All types**, **Flat endmill**, **Ball endmill**, **V-bit**, or **Drill**.
- **Units filter**: **All units**, **mm**, or **in**.
- Each row shows flute count and the tool's usable depth, and is badged **In project** or **New**
  so you can see at a glance what you already have.

Selection is multi-pick and survives filter changes: search for one thing, tick it, clear the
filters, search for another, and both stay selected. The action button counts what you picked —
**Import 4 tools** — and imports them in one go. Tools already in the project can't be imported twice.

	The original bundled entries are unchanged, so tools you imported from earlier versions still

	usable depth on the new sizes are interpolated from those same entries.

### Add a tool manually

Click **Add tool** to create a new tool with default values. Edit the tool properties in the right
panel. This is useful when your specific tool is not in the bundled library.

### Duplicate a tool

Click the duplicate icon (⧉) next to a tool in the list to create a copy. Useful for creating
variants of an existing tool with different feeds and speeds.

## Properties

Select a tool in the list to edit its properties in the right panel.

| Property | Description |
| --- | --- |
| **Name** | A descriptive name for the tool, shown in operation dropdowns. |
| **Type** | **Flat endmill**, **Ball endmill**, **V-bit**, or **Drill**. V-carve operations only accept V-bits. |
| **Units** | The unit system for this tool's dimensions (**Millimeters** or **Inches**). Tools can be used in projects with a different unit; values are converted automatically. |
| **Diameter** | The cutting diameter of the tool. |
| **V angle** | The included angle of a V-bit in degrees (V-bits only). |
| **Flutes** | Number of cutting flutes. Used for chip load calculations. |
| **Material** | **Carbide** or **HSS**. Informational only. |
| **Default RPM** | Spindle speed used as the default when this tool is assigned to an operation. |
| **Default feed** | Cutting feed rate used as the default when assigned to an operation. |
| **Plunge feed** | Plunge (Z-axis) feed rate used as the default. |
| **Stepdown** | Default depth per pass. |
| **Max cut depth** | Maximum total cutting depth. Set to 0 for no limit. Used by V-carve operations to limit carve depth. |
| **Stepover ratio** | Default stepover as a fraction of the tool diameter (0.01–1.0). For example, 0.4 = 40% of diameter. |

<Aside type="tip">
	Default values from the tool are applied automatically when you assign the tool to an operation.
	You can override any value per-operation without changing the tool definition.
</Aside>

### Deleting tools

Click the ✕ button next to a tool to delete it. Tools that are currently assigned to one or more
operations cannot be deleted — the delete button is disabled and shows a tooltip explaining why.
Remove the tool from all operations first, then delete it.

## Plasma torches

<Availability kind="experimental" />

In a **Plasma** project, **Add tool** creates an example torch and **Type** offers **Plasma**.
The library offers torches only. In other project types it offers milling tools instead.
This choice follows project type, regardless of the selected machine. Retained tools of
another type remain listed and editable; a torch cannot be assigned to a milling operation.

| Torch field | Meaning |
| --- | --- |
| **Kerf width** | Width removed by the torch, in tool units. This replaces cutter diameter. |
| **Cut feed** | Cutting speed in tool units per minute. |
| **Pierce height** | Height above the sheet for piercing, in tool units. |
| **Cut height** | Nominal torch height above the sheet while cutting, in tool units. |
| **Pierce delay (s)** | Time between torch on and the drop to cut height, in seconds. |
| **Plunge feed** | Speed of that drop, in tool units per minute. Required for G-code-owned piercing. |
| **QtPlasmaC material number (optional)** | Your controller's material-table entry. Optional in the tool editor, required for QtPlasmaC export; use an integer from 1 to 999999. |

The bundled **Powermax45 XP 45 A — 2 mm mild steel (example)** has a matching
**Powermax45 XP 45 A — 2 mm mild steel (example) — inch units** entry. These are editable
starting values for shielded 45 A air cutting of 2 mm mild steel:

| Setting | Metric entry | Inch entry, rounded |
| --- | --- | --- |
| Kerf | 1.4 mm | 0.05512 in |
| Cut feed | 5560 mm/min | 218.89764 in/min |
| Pierce height | 3.8 mm | 0.14961 in |
| Cut height | 1.5 mm | 0.05906 in |
| Pierce delay | 0.2 s | 0.2 s |
| Plunge feed | 300 mm/min | 11.81102 in/min |

A manually added torch uses the same example values in its units. Material number starts
unset because it belongs to your controller installation. Lengths and feeds convert between
tool and project units; delay and material number do not. Check your consumable's cut chart
and test your own settings. QtPlasmaC uses its material table for the actual cutting settings;
Grbl plasma uses the torch fields for the pierce and drop sequence.
