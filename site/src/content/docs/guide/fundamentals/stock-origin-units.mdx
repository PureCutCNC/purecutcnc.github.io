The stock is the material the job starts from, the origin is the point that becomes X0 Y0 Z0 on
the machine, and the units decide how every number in the project is read. Set all three before
you add operations, and check them again before you export.

In project coordinates, the bottom of the stock is at Z 0 and its top is at the stock thickness.
**Z top** and **Z bottom** of every feature use these coordinates.

## Stock


<Screenshot
	src={stockProperties}
	alt="Stock selected in the project tree, with Name, Width, Height, Thickness, Color, and Visible in the properties panel, next to the canvas showing the stock outline labelled 4 in and 3 in"
	caption="Rectangular stock. A shape used with Use as stock shows a Source feature here instead of Width and Height."
/>
<Steps>

1. Select **Stock** in the feature tree.

2. For rectangular stock, set **Width**, **Height**, and **Thickness**. **Color** and **Visible**
   only change how it is drawn.

3. To resize the stock from the canvas instead, click one of its dimension labels (for example
   **4 in**). In the **Resize stock** panel, type the new value. The panel says which side stays in
   place, for example **Holding left side**; **Flip held point** holds the opposite side instead.
   Click **Apply**.

</Steps>

Stock does not have to be a rectangle. To use a shape as the stock outline:

<Steps>

1. Draw the outline as a closed add feature.

2. Right-click it and choose **Use as stock**. The feature leaves the feature tree and becomes the
   stock outline, and the stock thickness is set to the feature's **Z top**.

3. Select **Stock**. Its properties show the **Source feature**, and **Thickness** is still
   editable. Use **Edit sketch** to change the outline, or **Reset to rectangle** to go back to
   rectangular stock.

</Steps>

The stock has no material setting. Clamps are separate objects; see
[Clamps and clearances](/guide/cam-setup/clamps-and-clearances/).

## Origin


<Screenshot
	src={originPlacement}
	alt="Origin selected in the project tree, with Z, a Place origin button, and Top left, Center top, and Bottom left presets in the properties panel, and the labelled origin marker at the lower-left corner of the stock on the canvas"
	caption="The marker on the canvas is the work zero that exported G-code is written against."
/>
The origin is the work zero: export writes every coordinate relative to it (**Export uses the
current project origin as machine X0 Y0 Z0.**). A new project puts it at the bottom-left corner of
the stock, as seen in the Sketch view, on the top surface.

<Steps>

1. Select **Origin** in the feature tree.

2. Set the XY position:

   - click **Place origin**, then click the sketch (**Click the sketch to place machine X0 Y0.**);
   - or click a preset:

     | Preset | Origin |
     | --- | --- |
     | **Top left** | The top-left corner of the stock in the Sketch view, on its top surface. |
     | **Center top** | The centre of the stock, on its top surface. |
     | **Bottom left** | The bottom-left corner of the stock in the Sketch view, on its bottom surface (Z 0). |

3. Check **Z**. **Place origin** does not change it, and the presets set it to the top or bottom of
   the stock. Set **Z** to match where you will touch off the tool on the machine.

</Steps>

<Aside type="danger" title="Safety: the origin must match your work zero">
	If the origin in the project and the work zero set on the machine differ, every move in the
	program is offset by the difference, including Z. Before running a job, confirm that you zero X,
	Y, and Z at the same place as the project origin. See [Working safely](/guide/start-here/safety/).
</Aside>

## Units


<Screenshot
	src={unitConversion}
	alt="Change project units dialog showing an in to mm conversion with two choices: Convert values, marked Recommended, which preserves physical size so 1 in becomes 25.4 mm, and Keep numeric values, which reinterprets the numbers"
	caption="Convert values keeps the part the same physical size; Keep numeric values changes it."
/>
A project is in millimetres or inches. To change it, click the units button in the status bar (for
example **INCH**) or change **Units** in the **Project** properties. The **Change project units?**
dialog asks how to treat the existing numbers:

| Choice | Result |
| --- | --- |
| **Convert values** (**Recommended**) | Keeps the physical size. Every length in the design, stock, dimensions, and operations is converted, so 1 in becomes 25.4 mm. |
| **Keep numeric values** | Keeps the numbers and reads them in the new units, so 1 in becomes 1 mm. The project's physical size changes. |

Tools keep their own units: a 1/4″ endmill stays a 1/4″ endmill in a metric project. Each tool's
**Units** is shown in its properties.

<Aside type="caution" title="Keep numeric values rescales the job">
	**Keep numeric values** changes the real size of the stock, the geometry, and every machining
	value by a factor of 25.4. Use it only to fix a project that was set up in the wrong units, and
	check the stock, the origin, and the toolpaths afterwards.
</Aside>
