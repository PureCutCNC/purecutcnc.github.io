A project holds everything about one job: the stock, origin, and units, the features, the tools,
the operations, the selected machine, and the tabs and clamps. It is saved as a single `.camj` file.

## Create a new project


<VisualPending id="projects-new-project" />
<Steps>

1. Click **New project** in the top toolbar.

2. Enter a **Project name**, then choose a **Template**:

   | Template | Starts with |
   | --- | --- |
   | **Blank metric** | An empty project in millimetres, with a 100 × 80 × 20 mm stock. |
   | **Blank imperial** | An empty project in inches, with a 4 × 3 × 0.75 in stock. |
   | **Current project** | The open project's setup (units, stock, origin, grid, tools, and machine) without its features, operations, tabs, or clamps. |
   | **Template file** | The same setup, taken from a `.camj` file you load. |

3. Check the **Template preview**. It lists the **Units**, **Stock**, **Features**, **Tools**,
   **Operations**, and **Machine** the new project starts with.

4. Click **Create project**.

</Steps>

Then check the stock, origin, and units; see
[Stock, origin, and units](/guide/fundamentals/stock-origin-units/).

If the open project has unsaved changes, PureCutCNC asks **You have unsaved changes. Discard them
and continue?** before it replaces the project. Cancel and save first if you want to keep them.

## Examples


<VisualPending id="projects-examples" />
The **New project** dialog also lists bundled examples under **Or open an example**:

| Example | Shows |
| --- | --- |
| **PureCutCNC** | Pocket and V-carving |
| **T Style guitar body** | Pocket, drilling, and edge route outside |
| **Badge** | Pocket, drilling, rest machining, and edge route outside |

The same examples appear on the **Start your part** card that an empty workspace shows, next to
**Draw a shape** and **Import a file**. An opened example is an ordinary project: save it under a
new name if you want to keep the original unchanged.

## Open and save

<Steps>

1. To open a project, click **Open project** and choose a `.camj` file.

2. To save, click **Save project**. The button is highlighted while there are unsaved changes.

3. In the desktop app, **File** > **Save** writes to the file you opened or last saved, and
   **File** > **Save As…** saves under a new name or location.

</Steps>

In a browser, every save asks where to save the file, or downloads it if the browser cannot show a
save dialog. The browser does not remember the file you opened, so choose the same file to replace
it.

On a tablet, projects are saved with the extension `.camj.json`, because tablet file pickers do not
recognise `.camj`. PureCutCNC opens both.

<Aside type="tip" title="Save checkpoints">
	Save before changing units, replacing the stock, or making a wide edit to linked features, so you
	have a version to go back to.
</Aside>

## Project name and format

The project name is shown at the left of the top toolbar, followed by **Saved** or **Unsaved**.
Click the name to rename the project. The name is also the suggested file name when you save and
when you export G-code.

A `.camj` file contains the whole job, including the machining setup and a copy of the selected
machine definition, so another PureCutCNC user can open it and export the same G-code. Your
appearance, language, and machine library are not part of the project. The file contents are
described on [File formats](/guide/reference/file-formats/#camj).
