## How it works

Trochoidal cutting advances a series of overlapping cutter orbits instead of taking one wide bite.
It can reduce peak engagement in tight material, but produces a longer, denser toolpath than a
simple offset or parallel pass.

## Settings

| Setting | Description |
| --- | --- |
| **Cut width** | Sets the width of the orbiting channel. |
| **Advance** | Sets forward progress between orbit centres. |
| **Channel width** | Shows the available widened slot for trochoidal Engrave. |

## Clearing


<VisualPending id="trochoidal-clearing" />
For pocket, surface-clean, and 3D-rough operations, **Cut width** controls the orbiting channel
width and **Advance** controls forward progress between orbits. Ring links join coverage where
possible; narrow or tight areas can force fallback behaviour. A finish-floor orbit rule preserves
the intended floor coverage when a finish pass is enabled.

## Edge routes


<VisualPending id="trochoidal-edge-route" />
For a rough edge route, Trochoidal widens its orbits toward the wall. Check the generated path for
tabs and warnings: a degenerate guide, an invalid guide, or the move budget can prevent the
expected path from being emitted.

## Slots

For Engrave, the trochoidal strategy widens a line into a channel. The available channel width is
shown with the strategy controls; use a tool and width that leave enough material for the orbit.

## Limitations

<Aside type="caution" title="Corner relief is unavailable on trochoidal pockets">
	Corner relief needs a contour path through the corner. Trochoidal pocket orbits do not trace
	that path, so use a compatible non-trochoidal pass when a dogbone or T-bone relief is required.
</Aside>
