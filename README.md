# PureCut CNC — public website

The marketing and documentation site for [PureCut CNC](https://github.com/PureCutCNC/purecutcnc),
a browser-based 2.5D + 3D CAD/CAM workspace for CNC work.

Live at **https://purecutcnc.github.io**. The site is an Astro + Starlight project in
[`site/`](site/README.md). Every push to `main` runs `.github/workflows/site.yml`, which
builds it and deploys it to GitHub Pages.

## Layout

| Path | What it is |
|------|------------|
| `site/` | The site source: landing and downloads pages, Quick Start, and the User Guide. |
| `downloads/` | Per-platform release metadata JSON (**auto-generated by CI**). |
| `app/`, `app-rc/` | The deployed stable / preview web-app builds (**auto-generated by CI**). The build copies them into the site unchanged. |
| `planning/` | Site platform runbooks, the manual blueprint, coverage and visual inventory. |
| `index.html`, `quickstart.html`, `downloads.html`, `guide/`, `images/` | The old hand-written site, kept only for rollback. Not served. |

## Local preview

Node 22.12 or newer. From `site/`:

```
npm ci
npm run dev
# open http://localhost:4321/
```

`npm run build` then `npm run preview` serves the built artifact, and `npm run ci` runs the
same checks as CI. See [`site/README.md`](site/README.md) for every command.

## Editing

Some files here are written by automation (the download metadata and the deployed
`app/` / `app-rc/` builds are pushed by CI from the app repo on release/deploy).
**Before editing anything, read [`AGENTS.md`](AGENTS.md)** — it covers which files
are hand-maintained vs. generated, how the download cards and version badge get
their data, and the checklist for updating the site when a new version ships.

Contributions go through a branch + PR against `main`. Merging deploys the site.
