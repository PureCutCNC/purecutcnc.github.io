# PureCut CNC — public website

The marketing and documentation site for [PureCut CNC](https://github.com/PureCutCNC/purecutcnc),
a browser-based 2.5D + 3D CAD/CAM workspace for CNC work.

Live at **https://purecutcnc.github.io** (served from `main` via GitHub Pages).
It's a plain static site — HTML, CSS, and JS with **no build step**.

## Layout

| Path | What it is |
|------|------------|
| `index.html` | Landing page. |
| `quickstart.html` | Quick-start guide. |
| `downloads.html` | Desktop download page (reads `downloads/*/*.json`). |
| `guide/` | Documentation pages + the shared `icons.svg` sprite. |
| `images/` | Screenshots and site imagery. |
| `downloads/` | Per-platform release metadata JSON (**auto-generated by CI**). |
| `app/`, `app-rc/` | The deployed stable / preview web-app builds (**auto-generated by CI**). |
| `site/` | Source of the new generated site (not deployed yet). |

## Local preview

No install or build needed — just serve the folder:

```
python3 -m http.server 8000
# open http://localhost:8000/
```

## Editing

Some files here are written by automation (the download metadata and the deployed
`app/` / `app-rc/` builds are pushed by CI from the app repo on release/deploy).
**Before editing anything, read [`AGENTS.md`](AGENTS.md)** — it covers which files
are hand-maintained vs. generated, how the download cards and version badges get
their data, how to sync the shared icon sprite, and the checklist for updating the
site when a new version ships.

Contributions go through a branch + PR against `main` (the live site).
