Choose a Track

Stable or Preview Build

Stable is the safer install for regular use. Preview Build is the newest in-progress desktop build and is better for testing recent changes before the next full release.

  • Choose stable if you want the most conservative desktop build.
  • Choose Preview Build if you are validating current work or checking a recent fix.
  • If a platform/track has no package yet, that card will stay unavailable until the next build is published.
No Install

Browser app still works

If you just want to test features quickly, the web build is still the fastest path. Desktop packages are mainly for platform-specific validation and local install workflows.

System Requirements

What you need

  • Browser app: a current desktop or tablet browser (Chrome, Edge, Firefox, or Safari) with WebGL2 — the GPU heightfield simulation requires it.
  • Desktop builds: macOS 11+ (universal), Windows 10/11 (x64), Linux x86_64 with glibc 2.31+ (AppImage or .deb).
  • Project data stays on your machine. No account, no cloud storage, no upload.
